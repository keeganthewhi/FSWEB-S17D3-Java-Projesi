## About

Covers building RESTful APIs with Spring Boot, including controllers, request mapping, and HTTP method handling. This assignment demonstrates how to create CRUD endpoints following REST conventions.

## Key Concepts

- `@RestController` and `@RequestMapping`
- HTTP methods: `@GetMapping`, `@PostMapping`, `@PutMapping`, `@DeleteMapping`
- Path variables and request parameters
- Response status codes and `ResponseEntity`
